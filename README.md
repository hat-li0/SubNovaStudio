# SubNova Studio — استوديو سوب نوفا للترجمة والتحسين الفائق لملفات الشاشة والفيديو ✨
> **المطور وصاحب المشروع:** **حاتم الحربي (Hatim Alharbi)** — © 2026 جميع الحقوق محفوظة

برنامج احترافي متكامل لترجمة وتدقيق وتحسين ملفات الترجمة (ASS / SRT / VTT) مع **استخراج تلقائي فوري وكامل التنسيقات من ملفات الفيديو** (MKV, MP4, AVI, MOV) بأعلى جودة لغوية وسينمائية تضاهي عمل كبار المترجمين وفرق الفانسب العالمية، مع تصفية ذاتية فورية لكافة الشوائب وحصانة كاملة لوسوم Aegisub.

تم دمج وتطوير هذا النظام ليجمع بين:
1. **نظام استوديو الترجمة المتقدم (`gpt_subtitler`)**: واجهة حديثة، إدارة شخصيات وقواميس، ذاكرة ترجمة (TM)، فحص تلقائي لبيانات الأعمال والشخصيات، ودعم مختلف مزودي الذكاء الاصطناعي (LM Studio، Ollama، Gemini، OpenAI).
2. **محرك التحسين والتنقية الفائق (`improve subtitle`)**: القواعد الذهبية لكسر الترجمة الحرفية، محرك التنقية الذاتي (Smart Auto-Healing)، إزالة الشوائب اللاتينية، ضبط الفواصل وعلامات الاستفهام العربية، ومعالجة علامات التنصيص.
3. **محرك استخراج الترجمة من الفيديو (`VideoSubtitleExtractor`)**: فحص الفيديو واستخراج مسار الترجمة بالكامل بنسخ البت المباشر (`-c:s copy`) للحفاظ على 100% من التنسيقات والأنماط والألوان والمواقع ومؤثرات Aegisub دون أي تلف.

## 🌟 الميزات والمواصفات الرئيسية

### 🎬 1. ميزة الاستخراج والترجمة التلقائية من الفيديو (Automated Video Pipeline)
- **سحب وإفلات الفيديو مباشرة**: اسحب ملف الفيديو (أو مجلد فيديوهات) وضعه في البرنامج، وسيقوم تلقائياً بفحص مسارات الترجمة المدمجة.
- **استخراج مطابق للأصل بنسبة 100% بدون تلف**: يعتمد على محرك `ffmpeg` بأمر النسخ الخام (`-c:s copy`) لاستخراج ملفات `.ass` أو `.srt` مع كامل التنسيقات والخطوط والمؤثرات وألوان الأنماط دون إعادة ترميز أو فقدان أي وسم.
- **انتقاء ذكي لمسار الحوار**: إذا كان الفيديو يحتوي على مسارات متعددة (مثل مسار حوار كامل ومسار لوحات وأغاني فقط)، يفرز البرنامج المسارات ويقترح مسار الحوار الكامل تلقائياً مع نافذة لاختيار المسار المناسب.
- **تشغيل تلقائي متكامل بنقرة واحدة**: فور اختيار الفيديو، يستخرج الترجمة ➔ يتعرف تلقائياً على اسم العمل والشخصيات ➔ يبدأ الترجمة والتحسين ➔ ويحفظ ملف الترجمة النهائي بجانب ملف الفيديو مباشرة ليعمل فورياً في مشغلات الفيديو (VLC, MPC-HC, mpv).

### 2. خط إنتاج ثنائي المراحل فائق الجودة (2-Stage Localization Pipeline)
- **المرحلة الأولى (الترجمة السياقية الذكية)**: ترجمة سينمائية فصيحة تأخذ بعين الاعتبار سياق المشاهد السابقة واللاحقة وأجناس الشخصيات المتحدثة.
- **المرحلة الثانية (التحسين والتدقيق اللغوي الفائق)**: مراجعة دقيقة للصياغة لتجاوز ركاكة الترجمة الآلية، ضبط همزات الوصل والقطع، وضمان سلاسة العبارات وسرعة قراءتها على الشاشة.
- **التنقية التلقائية الفورية (Smart Auto-Healing)**: تصفية الشوائب بعد كل دفعة لحماية وسوم ASS وضبط الترقيم العربي.

### 3. محرك التنقية الذاتي والمعالجة الشاملة (Smart Auto-Healing Engine)
- **حصانة وسوم ASS بنسبة 100%**: حماية وسوم التنسيق والمؤثرات مثل `{\an8}` و `{\pos()}` و `{\c&H...&}` و `\N` من الضياع أو التشويه واستعادتها آلياً.
- **تصفية الشوائب اللاتينية والهلوسة**: إزالة الحروف والضمائر الإنجليزية العالقة (مثل `\NI` و `\Na`) وأقواس الأفكار `{Hmm.}`.
- **تصحيح علامات الترقيم العربية**: تحويل الفواصل الإنجليزية `,` إلى `،` وعلامات الاستفهام `?` إلى `؟` والمنقوطة `;` إلى `؛`.
- **معالجة علامات التنصيص اليتيمة**: حذف أي علامات تنصيص غير متطابقة أو غير مغلقة في نهاية وبداية الأسطر.
- **زر التنقية الفورية (Quick Zero-Token Healing)**: إمكانية تصفية وتنقية أي ملف ترجمة محلياً في أجزاء من الثانية بدون استهلاك أي رموز ذكاء اصطناعي.

### 4. دعم شامل لمزودي الذكاء الاصطناعي مع كشف تلقائي
- **🤖 LM Studio (محلي)**: كشف تلقائي مستمر للنماذج المحملة وتحديث الحالة فورياً (`🟢 متصل تلقائياً بـ LM Studio`).
- **🦙 Ollama (محلي)**: دعم كامل للنماذج المحلية المفتوحة المصدر.
- **✨ Google Gemini**: دعم أحدث نماذج جيميناي (`gemini-2.5-flash`, `gemini-1.5-pro`).
- **⚡ OpenAI**: دعم نماذج `gpt-4o` و `gpt-4o-mini`.
- **🌐 Custom OpenAI-Compatible**: دعم أي مزود أو خادم وسيط متوافق مع واجهة OpenAI.

### 5. واجهة استخدام متطورة وتجربة مستخدم مريحة
- **معاينة حية مباشرة (Live Preview)**: عرض النص الأصلي مقابل النص المترجم والمحسن لحظة بلحظة أثناء المعالجة.
- **دعم السحب والإفلات (Drag & Drop)**: اسحب ملفات الترجمة أو الفيديوهات أو المجلدات بأكملها مباشرة إلى نافذة البرنامج.
- **تنبيه صوتي**: تشغيل نغمة مميزة عند انتهاء المعالجة.
- **حفظ تلقائي بجانب الفيديو**: حفظ ملف الترجمة المترجم والمحسن بنفس اسم الفيديو ومجلده (`VideoName.ara.ass`).

## 🚀 طريقة التشغيل

### المتطلبات
- مثبت Python 3.10 أو أحدث.
- وجود `ffmpeg` و `ffprobe` (متوفران ومثبتان مسبقاً على نظامك).
- تثبيت المكتبات المطلوبة:
```bash
pip install -r requirements.txt
```

### التشغيل المباشر
- اضغط مرتين على ملف:
  **`run.bat`**
- أو عبر موجه الأوامر:
```bash
python main.py
```

### إنشاء اختصار على سطح المكتب (Desktop Shortcut)
قم بتشغيل السكربت التالي لإنشاء اختصار مباشر على سطح المكتب:
```bash
python create_shortcut.py
```

## 🛠️ الصيغ المدعومة
- **ملفات الفيديو المدعومة للاستخراج التلقائي**: `.mkv`, `.mp4`, `.avi`, `.mov`, `.flv`, `.wmv`, `.webm`, `.ts`, `.m4v`
- **صيغ الترجمة**:
  - **Advanced SubStation Alpha** (`.ass`, `.ssa`) مع الحفاظ الكامل على أنماط Aegisub ومؤثراتها.
  - **SubRip** (`.srt`)
  - **WebVTT** (`.vtt`)
  - **YouTube SBV** (`.sbv`)
  - **JSON Subtitles** (`.json`)
  - **Plain Text Dialogues** (`.txt`)
